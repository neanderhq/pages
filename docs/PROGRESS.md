# Maintenance

Current setup and supported behavior are documented in the [README](../README.md)
and [limitations](limitations.md). Use the source commit, CI results and release
record for verification. Historical delivery claims are not current test evidence.

Dependency updates, security fixes and product improvements follow ordinary
pull requests and required checks. The private Neander publisher registers
verified changed main commits; existing user deployments need their normal
republish to receive a new image.
