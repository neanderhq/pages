Follow the current [README](../README.md) for locked install, local PostgreSQL,
generated credentials, migrations, fictional seeding and startup. The application

[testing](testing.md) for disposable production-image verification. Published
instances use PostgreSQL and HTTPS. Optional email uses only your own provider
