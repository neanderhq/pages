# Pages walkthrough

1. Start the app using the README and sign in to a fictional seeded workspace,
   or create your own independent workspace with **Create a workspace**.
2. Browse team spaces and the page tree. Open a page, edit rich content as an
   Admin/Editor, and wait for **Saved** before switching pages.
3. Add a subpage or table, upload an allowed attachment and review history.
   Viewers may read permitted content but do not gain edit/comment access.
4. Use page or inline discussions and mention a permitted teammate. Choose a
   suggested recipient, then save the comment or reply to notify them.
5. Inspect Members, Groups and sharing settings. The server applies workspace
   roles, inherited grants and tenant isolation; UI visibility is not authorization.
6. Export Markdown, reimport a copy or explicitly publish a snapshot. Private
   later edits do not silently update an existing public snapshot; revoke it
   when it should no longer be public. Save as PDF uses browser printing.
7. Archive and restore an authorized page tree, or mark a page reviewed and
   inspect its review interval. Email notifications require your own provider.

Use only fictional records while exploring the template. See the
[role matrix](ROLE_MATRIX.md) for precise permission behavior and the
[backup guide](BACKUP_RESTORE.md) before working with important data.
